## Ejecutar una solución

Requiere [ts-node](https://typestrong.org/ts-node/) o [Bun](https://bun.sh/):

```bash
# Con ts-node
npx ts-node 01-two-sum.ts

# Con Bun (más rápido)
bun run 01-two-sum.ts
```
